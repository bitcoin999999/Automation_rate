# Automation_rate

This repository contains several Streamlit applications. The new `inventory_app.py` provides a simple warehouse inventory management system with the following features:

- Visual 2D layout of four shelves with four levels each
- Click a location to view items stored there
- Add or remove items at each location
- Search for items by name and view their location
- Export the complete inventory to Excel

Run it with:

```bash
streamlit run inventory_app.py
```
